# 阶段 3：附图

## 单一编辑源

**一个 PPT 文件装全部附图，每页一张，页序即图号。** 固定命名 `figures/附图合集.pptx`。不允许同一张图存在两份可编辑源。

早期把几张图拆成几个独立文件，很快就出现「改了哪一份」的混乱。往后所有修订都在合集的对应页上做，PNG 从合集按页导出。

**论文已有框架图的 PPT 时，复制一份作底改**，原文件不动。删论文图里的元素要有规定依据或作者同意，外框和论文标题可以删。实测：第二篇曾自行删掉小狗示例图和表示参数冻结的雪花图标，作者指出图不全。**一张框架图能讲清的，不再分模块单独画。** 流程图新画。

## 合规硬点

- **摘要附图必须是说明书附图之一。** 做法是把流程图编进说明书附图，请求书里指定它作摘要附图。摘要附图那个单独的 docx 文件里不带图号标注。
- **摘要附图的步骤框与发明内容的 S1–Sn 一一对应**：框数等于步数，每框文字是对应步骤的浓缩，顺序一致，不多不少。代理机构批注「步骤需要与发明内容一致」针对的就是这条。
- **流程图（含摘要附图）用黑色线条**，不着色、不加底纹。**其他附图不限制颜色**，论文框架图的原配色可以保留。《专利审查指南》（2023）第一部分第一章 4.3 的原文是「附图一般使用黑色墨水绘制，必要时可以提交彩色附图，以便清楚描述专利申请的相关技术内容」，是否属于「必要时」以代理机构的意见为准。
- 图内文字用中文。
- **照片由作者决定，不要直接删。** 《专利审查指南》（2023）第一部分第一章 4.3 写的是「一般不得使用照片作为附图」，例外举的是金相结构、组织细胞、电泳图谱。论文框架图里有示例照片时，先告诉作者这条规定，给出保留照片、改成线稿、改成方框几种做法，由作者定。保留照片的可能被要求补正，要提醒请代理机构确认。
- 示例取值换成通用文字或符号，不把专利绑在某个具体例子上。

## 统一的样式标准

同一套图里所有元素的样式必须一致，否则看起来像拼凑的。

| 项 | 值 |
|---|---|
| 数据流箭头 | 用真正的连接线，连到形状的连接点；统一线宽、实心三角箭头；流程图用黑色 |
| 装饰线（轮廓连线、放大指示虚线） | 不加箭头 |
| 双向箭头 | 保留双向，两端箭头形状统一 |
| 字体 | 中文宋体，西文 Times New Roman；不留论文图原来的字体 |
| 字号 | 全图统一，不混用多种字号 |
| 框尺寸 | 同类框统一尺寸，为最长的那条文字留够宽度 |
| 纵向间距 | 统一，不要肉眼可见的不齐 |
| 水平位置 | 居中对齐到页面中轴 |
| 填充 | 流程图显式白底黑框，不依赖 PPT 默认样式，去掉阴影；其他图可保留原配色 |
| 页面 | 宽度不超过 A4 版心，避免放进 Word 后缩得太小 |

## 人机分工

- **Agent 用 `python-pptx` 生成和修改 PPT。** 改已有 PPT 时要递归进组合形状，文字和字体声明都要全量替换，改完逐项核对没有残留。保留原配色时，深色底上的浅色文字要一并保留，不能统一改成黑字。
- **导出 PNG 用 `scripts/export_pptx_png.py --project <版本目录>`。** 它让 PowerPoint 存成 PDF，再按 300 dpi 转 PNG 并裁掉白边，页序对应 `patent.json` 的 `figures`。只支持 macOS，本机要装 PowerPoint，没有时由用户手工导出。踩过的坑：PowerPoint 是沙盒应用，AppleScript 零报错，但文件不落在指定路径，而落在 `~/Library/Containers/com.microsoft.Powerpoint/Data.pdf`。曾只看指定路径，误判成「脚本导不出」。
- **看版面要看导出的 PNG，不要看 Quick Look。** `qlmanage` 不画上标、斜纹底和部分叉号，只渲染第一页，只能用来快速确认文件能打开。
- **导出后 agent 自己先看一遍图，再请用户看版面。**

## 两个必查

1. **改 PPT 前先查 `figures/` 下有没有 `~$*.pptx` 锁文件。** PowerPoint 和 Word 一样，读进内存后不再盯磁盘，开着时脚本写入零报错，用户一保存就把改动静默覆盖。
2. **图文一致性要核图内的每个词，不能凭图号推断。** 曾经断定「四张图都含待改术语，必须一起重画」，逐图核对文字后发现其中一张用的是另一个词，根本不受影响。结论下在图号层面就会失真。

## 改术语时的连带范围

改一个术语，要一起改的地方：正文（说明书、权利要求书、摘要）、附图内的文字、**附图说明里的图题**。图题最容易漏，因为它在正文里，看起来不像「图的事」。

## 把新图换进 Word

Word 内嵌图片不会因为 PNG 文件更新而自动更新。三种做法：

| 做法 | 有没有修订痕迹 | 何时用 |
|---|---|---|
| 用户在 Word 里「更改图片」 | 无 | 成稿阶段，没有修订要求时 |
| 脚本替换 `word/media/imageN.png` 字节 | 无 | 同上，且 Word 必须关着 |
| **修订模式下删旧图 + 插新图** | **有**（旧图包在 `w:del`、新图包在 `w:ins`） | 给代理机构回稿时 |

第三种是实测可行的：Word 会照常留痕，作者名同样按当前登录账户判定。所以在带修订要求的文件里换图，不必额外发邮件说明「换过图」，痕迹自己看得见。
